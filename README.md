# RadarBeacon

**门边雷达发现有人 → 床头灯无线亮起**

24GHz 毫米波人体存在雷达（HLK-LD2410C-P）+ 两块 ESP32-C3 SuperMini，用 ESP-NOW 把「有人」这个信号无线送到床头，点亮一颗 LED。

> A 24GHz mmWave presence radar that lights a bedside LED over ESP-NOW.

---

## 它解决什么问题

宿舍门关着的时候，你坐在屋里听不见走廊的动静。这套东西在门边放一个雷达，探到有人靠近就通过 ESP-NOW 通知床头那块板子，让 LED 亮起来。

- **雷达不是红外**：HLK-LD2410C-P 是 24GHz 毫米波，能测到「静止不动的人」，不是只有挥手才触发。
- **不需要路由器**：ESP-NOW 是点对点的 2.4GHz 链路，两块板子配好 MAC 就能通信，不用连 WiFi 热点。
- **有兜底**：发射端在有人期间每 2 秒心跳重发；接收端 10 秒收不到任何包会自动灭灯（发射端掉线也不怕）。

## 硬件

| 件 | 数量 | 说明 |
|---|---|---|
| HLK-LD2410C-P | 1 | 24GHz 人体存在雷达。5 脚 `TX RX OUT GND VCC`，VCC 吃 **5V**，OUT 出 **3.3V** 电平 |
| ESP32-C3 SuperMini | 2 | 发射端 + 接收端。原生 USB-CDC，不需要 CH340 |
| 5V USB-C 输出的电池 | 2 | 一端一块，Type-C 线直插开发板 USB-C 口 |
| 红色 LED + 220Ω 电阻 | 各 1 | 接收端提示灯，接 `GPIO1` |
| 面包板 + 杜邦线 | 1 套 | 板子和雷达的排针都是**公针**，接线方式见教程第三节 |

470µF + 0.1µF 电容是**可选**件（吸收 WiFi 发射瞬间的电流尖峰，不装也能跑）。

## 快速上手

1. 按 [烧录教程.md](烧录教程.md) 装好 Arduino 环境。**`工具 → USB CDC On Boot` 必须设为 `Enabled`**，否则串口一片空白。
2. 先烧 `rx_mac` 读出接收端 MAC，填进 `tx_radar.ino` 的 `peerMac[]`。
3. 分别烧 `tx_radar`（发射端）和 `rx_alert`（接收端）。
4. 按 [硬件安装教程.md](硬件安装教程.md) 接线，对照 [接线总图.html](接线总图.html)。
5. 走到雷达前面 → 床头灯一直快闪；走开 → 立刻灭。

## 引脚接法

| 板子 | 用到 | 位置 |
|---|---|---|
| 发射端 | `5V` `G` `GPIO5` | `5V` / `G` 在含 5V 那排的第 1、2 个；`GPIO5` 在另一排第 1 个（丝印 `5`） |
| 接收端 | `G` `GPIO1` | 同在含 5V 那排：`G` 第 2 个，`GPIO1` 第 7 个（丝印 `1`） |

雷达 `VCC` → 板子 `5V`，`GND` → 板子 `G`，`OUT` → 板子 `GPIO5`，`TX` / `RX` 悬空。

> ⚠️ **5V 只能进 `5V` 脚**——`3V3` 是板上 LDO 的**输出**，把 5V 灌进去会烧板子。
> ⚠️ **任何 GPIO 都不能碰 5V**（耐压 3.3V）。雷达 `OUT` 本身就是 3.3V，直接接，不需要电平转换。

## 配置

两块固件里的信道必须一致：

```cpp
#define WIFI_CHANNEL 6
WiFi.setSleep(false);   // 关键：不关 modem sleep 会漏包
```

发射端的目标 MAC：

```cpp
uint8_t peerMac[] = {0xE8, 0x3D, 0xC1, 0x95, 0x0C, 0x94};  // 换成你自己的接收端 MAC
```

## 实测记录

40 分钟连续抓取：发射端 4 次「有人」事件对应接收端 4 次开始快闪，3 次「离开」对应 3 次灭灯，**0 丢事件**。

两个值得记住的实测经验：

- **ESP-NOW 的发送回调 ACK 状态不可靠**——经常报「接收端没回应」，但数据其实 100% 送达。判断链路要以**接收端的日志**为准，不要拿发送端那句话去排查问题。
- **USB CDC 的发送缓冲写满会阻塞整个 `loop()`**，表现是「程序像死了，灯停在某个状态不动、串口也没输出」。两块正式固件都在 `Serial.begin()` 之后加了 `Serial.setTxTimeoutMs(0)`，自己加打印时注意这点。
