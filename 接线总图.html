三、你的零件决定接法：全是公针 + 全是公对公线

现状 两块 SuperMini 和雷达的排针都是出厂已焊好的公针，手头的杜邦线也全是公对公。

核心矛盾：公对公的线插不到公针上。 杜邦线两头都是公头（针），板子和雷达的引脚也是公头（针）——两个公头没法对插。 所以只有两条路：走面包板，或者把公头焊在一起。

方式 A：全部走面包板（推荐）

  1. 把 SuperMini 跨着面包板中间凹槽插进去——两排针各落在凹槽两侧的一排孔里。
  2. 把 雷达也插在面包板上，5 根针占 5 个连续的孔。
  3. 把 220Ω 和 LED 插在面包板上（元件脚刚好能插进面包板孔）。
  4. 用公对公杜邦线在面包板孔之间跳线，把该连的孔连起来。
为什么推荐：不用烙铁、可随时拆改、不伤元件、不留焊锡。 发射端现在就能用——雷达直接吃板子 5V 脚上的电，不需要升压模块。
先量一下再插：面包板上能跨过中间凹槽、彼此对齐的两排孔，间距固定是 17.78mm（0.7″） （也就是 a 排到 f 排的距离）。先用卡尺/直尺量板子两排针的间距：
· 等于 17.78mm → 可以直接跨着凹槽插进去；
· 不等于 → 别硬按，硬按会把针别弯。改用一包母对母杜邦线（几块钱）， 一头夹板子公针、一头夹面包板上的公对公线头。

方式 B：直接焊公头（永久，最牢）

可以焊，但绝对不能头对头对焊。两个针尖顶在一起焊，看着连上了，一拉就断，焊点旁边还全是裸露的金属。

正确做法（并排叠焊）：

  1. 先拔掉所有电源（USB 线、电池开关）。在通电的板子上动烙铁容易短路或静电打死芯片。
  2. 两根针平行叠放，重叠 3–5mm。
  3. 先分别给两根针上锡，再靠在一起加热，让锡熔成一体。
  4. 先套热缩管再焊——针间距只有 2.54mm，不套热缩管相邻两根一碰就短路。
  5. 焊完轻拉一下确认牢固；再用通断档确认相邻两根针不导通。
更牢的做法：剪掉杜邦线一头，剥出 4–5mm 铜丝，把铜丝缠在针脚上再焊。 接触面积比两根针叠焊大得多，也比叠焊好操作。

关于"不焊开发板"这件事

不焊开发板是对的（板子还能复用）。但要注意一个连锁问题：

  • 如果雷达的针焊死了，雷达就再也插不进面包板了。焊过的地方会挂锡、变粗，硬插会把面包板孔撑松。
  • 所以两条路要选一条走到底：
    ① 雷达和板子都走面包板（现在的做法，推荐）；
    ② 雷达焊死、板子插面包板——那雷达那 3 根线要留够长度，而且雷达以后不能再拔下来插面包板。
  • 公头焊过一次之后再想插面包板基本就废了，别只焊一半又反悔。
发射端现在根本不用焊。雷达吃板子 5V 脚的电， 把板子和雷达都插在面包板上，三根公对公跳线（5V↔VCC、G↔GND、GPIO5↔OUT）就通了。

4.2 备选方案：用 18650 + 升压模块供电

只有在不用 5V USB-C 电池时才需要这一节。走这条路要另外准备三样： 18650 电池盒（带开关）、升压模块（Boost，别买成 LM2596 降压）、电容（可选）。

#从到线色备注
10电池盒 红线升压 IN+红接之前先不开开关
11电池盒 黑线升压 IN−黑
12升压 OUT+发射端 5V 脚（和雷达 VCC 同一点）红先空载调到 5.0V，再带载复测
13升压 OUT−发射端 G 脚（和雷达 GND 同一点）黑
14470µF（+ 接 5V）+ 0.1µF并接在雷达 VCC/GND 之间—可选；两只并联，引线越短越好
走这条路之后，发射端的 5V 脚上会同时有 USB-C 的 5V 和升压模块的 5V， 也就重新出现了「升压模块 5V 倒灌电脑 USB 口」的风险。 所以烧录前必须关掉电池盒开关，或者更稳一点：把升压 OUT+ 从 5V 脚上拔掉。
用 5V USB-C 电池直插的方案没有这个问题，因为一个 USB-C 口插不下两样东西。

五、上电与烧录顺序

现在（5V USB-C 电池供电）

板子上只有一个 USB-C 口，所以电池和电脑不可能同时插。顺序就两步：

  1. 刷固件：拔掉电池，把 Type-C 线插到电脑上，烧录。
  2. 刷完：拔掉电脑那根线，把 Type-C 线插到 5V USB-C 电池上。
没有任何倒灌风险。发射端和接收端各用各的电池，两块板子各自把上面两步走一遍就行。

备选方案（18650 + 升压模块，铁律）

场景电池盒开关Type-C 数据线升压 OUT+ 到 5V 脚
烧录固件时关插电脑拔掉（最稳）
日常使用开拔掉接上
接收端（没接升压模块时）—拔掉不适用
绝对不要在升压模块有 5V 输出（电池盒开关开着）的同时，把 Type-C 插进电脑。 升压模块的 5V 会倒灌进电脑 USB 口。

六、通电前的三项检查

  1. 量 5V 和 GND 是否短路——万用表通断档，表笔搭板子的 5V 脚和 G 脚，应该不响。响了就是哪根线搭错了。
  2. 量雷达的 VCC 和 GND——上电后黑笔固定在板子 G：
    雷达 VCC = 5.0V；雷达 GND = 0.0V（不是 0.4V！有压差说明地线虚接）；雷达 OUT = 有人 3.3V / 没人 0V。
  3. 量电池是不是真的在出 5V——插上 5V USB-C 电池后，黑笔固定板子 G，红笔搭板子 5V 脚， 读数应该是 4.9–5.2V。低了说明电池这个口没输出、线没插到底或插错了口。接收端同样量一次。

走备选方案（18650 + 升压模块）时再加一条：量升压模块的带载输出，必须落在 4.9–5.2V。

不要在通电状态下用通断档 / 电阻档去量。带电测电阻没有意义，读数会骗你。要查通断，先拔掉所有电源。

七、四条不能碰的红线

  • 5V 只能进 5V 脚。SuperMini 的 5V 脚和 Type-C 的 VBUS 直连；3V3 是板上 LDO 的输出，5V 灌进去会烧板子。
  • 任何 GPIO 都不能碰 5V。GPIO 耐压 3.3V。雷达 OUT 正好是 3.3V，可以直接接，不需要电平转换。
  • 470µF 电解的正负极不能反（如果装了这颗电容）。正极接 5V、负极接 GND，接反会爆。焊之前用万用表确认极性。
  • LED 方向不能反。长脚是正极，朝电阻那一侧；短脚朝 GND。脚剪短了就看侧面平切面，平切面那侧的脚是负极。
